# UPES-100-days-of-code# 💻 UPES 100 Days of Code

This repository contains my solutions for the **UPES 100 Days of Code Challenge**.

The goal is to consistently practice programming, strengthen problem-solving skills, and build strong fundamentals in C.

## 🚀 Challenge Format

- Days 1–50: 2 problems per day
- Days 51–100: 1 problem per day
- Language: C
- Duration: 100 Days

## 📚 Topics Covered

- User Input, Operations & Output
- Conditional Statements
- Loops
- Functions
- Arrays
- Strings
- Pointers
- Structures
- Problem Solving
